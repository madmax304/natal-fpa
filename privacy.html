Privacy policy

Natal FP&A — internal QuickBooks Online integration

Last updated: 19 September 2026

Who this covers

Natal FP&A is used solely by Natal to access Natal’s own QuickBooks Online company. It has no external users and collects no data from anyone else.

What data is accessed

Accounting data from the connected QuickBooks Online company: general ledger entries, chart of accounts, vendors, customers, items, transactions and standard financial reports. Access is read-only.

Where data is stored

Retrieved data is stored in a local database file on a company-controlled computer. OAuth tokens are stored in that computer’s operating-system keychain. No accounting data is stored on third-party servers by this application.

How data is used and shared

Data is used only for Natal’s internal financial reporting and analysis. It is not sold, rented or shared with any third party, and it is not used for advertising.

The finance team analyzes this data through an AI assistant operated by the company. When a query is run, the results of that query are processed by the assistant’s provider in order to produce the answer. No bulk export of the accounting database is transmitted.

Retention and deletion

The local copy is retained while the tool is in use and can be deleted at any time by removing the local database file. Disconnecting the application in QuickBooks Online revokes its access immediately.

Security

Credentials are held in the operating-system keychain rather than in files or source code. Access requires physical or authenticated access to the company-controlled computer. The application holds read-only authorization.

Natal FP&A is an internal tool. It is not offered to, sold to, or usable by the public.
